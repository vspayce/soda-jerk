# Where the scores come from

Every score here is a public-domain composition, from an edition its
typesetter placed in the public domain, so the notes are free to use in a
commercial app. The recordings made from them (render-tracks.mjs) are new
and belong to the game.

| File | Piece | Composer | Edition |
|---|---|---|---|
| entertainer.mid | The Entertainer (1902) | Scott Joplin (1868–1917) | Mutopia Project #263, public domain |
| maple.mid | Maple Leaf Rag (1899) | Scott Joplin | Mutopia Project #23, public domain |
| winners.mid | The Easy Winners (1901) | Scott Joplin | Mutopia Project #352, public domain |

The instrument is the honky-tonk piano from GeneralUser GS v2.0.3 by
S. Christian Collins (sf/GeneralUser-GS-LICENSE.txt), whose license allows
commercial use of recordings made with it. The .sf2 itself isn't committed
(30 MB): get it from https://www.schristiancollins.com and put it in sf/.
